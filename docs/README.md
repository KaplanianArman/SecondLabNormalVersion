# *MATH FORMULAS*

## *SQUARE*
### AREA
def area(a):
    return a * a

Функция **area** принимает в качестве аргумента одно целое положительно число(сторону квадрата)
и возвращает целое положительное число(площадь квадрата)

#### Примеры вызова функции:
area(3) = 3 * 3 = 9
area(5) = 5 * 5 = 25

### PERIMETER
def perimeter(a):
    return 4 * a

Функция **perimeter** принимает в качестве аргумента одно целое положительно число(сторону квадрата)
и возвращает целое положительное число(периметр квадрата)

#### Примеры вызова функции:
area(3) = 4 * 3 = 12
area(5) = 4 * 5 = 20


## *RECTANGLE*
### AREA
def area(a, b):
    return a * b

Функция **area** принимает в качестве аргумента два целых положительных 
числа(длину и ширину прямоугольника) и возвращает целое 
положительное число(площадь прямоугольника)

#### Примеры вызова функции:
area(3, 10) = 3 * 10 = 30
area(5, 1) = 5 * 1 = 5

### PERIMETER
def perimeter(a, b):
    return (a + b) * 2

Функция **perimeter** принимает в качестве аргумента два целых положительных 
числа(длину и ширину прямоугольника) и возвращает целое 
положительное число(периметр прямоугольника)

#### Примеры вызова функции:
area(3, 25) = (3 + 25) * 2 = 56
area(32, 5) = (32 + 5) * 2 = 74
